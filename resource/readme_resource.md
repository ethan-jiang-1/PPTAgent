# 资源管理说明

## 目录结构
resource/
├── templates/           # PPT模板文件
│   ├── default/        # 默认模板
│   └── custom/         # 自定义模板
├── images/             # 图片资源
│   ├── icons/         # 图标文件
│   └── backgrounds/   # 背景图片
└── styles/            # 样式配置
    └── theme/         # 主题样式

## 深度理解
- 模板系统设计：
  1. 默认模板提供基础PPT样式和布局
  2. 自定义模板支持用户特定需求
  3. 模板包含页面布局、样式和主题定义

- 资源组织结构：
  1. 图片资源按用途分类存储
  2. 样式配置支持主题化定制
  3. 资源文件采用模块化管理

- 资源调用机制：
  1. 通过统一的资源管理接口访问
  2. 支持动态加载和切换
  3. 确保资源的复用和维护性
